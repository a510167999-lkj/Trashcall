# prefix-entry-seed-policy

## 目标

1. `18964046784` 可以写入用户识别库，理论上也可以进种子库；**默认种子构建不写入它**。
2. 添加号码/号段不必手动打星号：输入前缀（如 `9521`）即按号段展开。
3. 用 GitHub 账号 `a510167999-lkj` 初始化仓库并推送。

## 决策

- 撤销 live path 上的 `ExcludedPhoneNumbers` 硬拦截（UI / `addUserRule` / bootstrap 清洗 / seed import 丢弃）。
- 种子脚本仍从默认黄页来源省略 `18964046784` / `8618964046784`（vCards 与号段生成都跳过），CI 只断言默认种子不含这两条，不阻止用户后写入。
- 无 `*`/`?` 的短输入按号段自动补最多 4 个 `*`（1 万个号码，低于 CallKit 单条 5 万上限）：`9521` → `9521****`；11 位手机号等完整号码仍精确标记。
- 界面展示将写入的号段与大约数量，避免把上万个号码拼进成功提示。
- 版本 `1.1.1` (10)。Git：`feat/prefix-entry-seed-policy`，私有仓库。

## 验收

- 用户添加 `18964046784` 后识别库同时有国内/国际两种形式；启动 bootstrap 不会删掉。
- 默认 `seed_database.sqlite` 不含这两条。
- 输入 `9521` 与输入 `9521****` 展开结果一致；输入完整 11 位号码不补星。
- `swift run TrashcallTestRunner` 全绿。
- GitHub 上 `a510167999-lkj/Trashcall` 能看到提交。
