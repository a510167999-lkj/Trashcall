# identify-only-db

## 目标

1. 删除自动挂断 / 系统拉黑引导，只保留来电标记。
2. 检查并修好种子库完整性，以及启动时从内置种子更新黄页。
3. `18964046784` / `8618964046784` 不得出现在种子库或用户库。

## 决策

- 只保留一个 Call Directory 扩展，只注入 identification；增量时 `removeAllBlocking` 清掉旧阻断。
- 原 4 万拦截号段改为打标（如「高频营销 9521」）。
- 种子版本写入 metadata；启动时若内置种子版本更新，则 upsert 黄页并保留用户规则。
- 排除号码在构建脚本、导入、启动清洗三处同时过滤。
